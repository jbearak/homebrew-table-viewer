# homebrew-table-viewer

A [Homebrew](https://brew.sh) tap for the standalone
[Table Viewer](https://github.com/jbearak/table-viewer) macOS app — a fast
viewer for Excel, CSV and TSV files.

> **Not ready yet.** This repository has been created but not yet seeded. The
> cask lands once a Table Viewer release carries the macOS app bundle; until
> then there is nothing here to install.
